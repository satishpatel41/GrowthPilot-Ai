# GrowthPilot AI

Multi-tenant AI digital marketing agency platform for local businesses in India.

## Status

Planning and UI design stage. No application code yet.

| Path | Contents |
| --- | --- |
| `docs/master-project-prompt.md` | Full product brief and phased build plan |
| `design/screens/` | UI screen designs (`.dc.html` artboards and `canvas.json` layout) |

## Screens designed

Public home and pricing, customer onboarding, customer dashboard, content calendar and approvals, AI assistant, leads pipeline, mobile dashboard, agency admin dashboard, admin plans and pricing.

Dashboard and admin figures are sample data for design review only. Prices and limits are `[placeholders]` until the agency sets them.

## Planned stack

Next.js, TypeScript, Tailwind, shadcn/ui, NestJS, PostgreSQL with Prisma and row-level security, Redis with BullMQ, Razorpay, Claude API, AWS S3.
